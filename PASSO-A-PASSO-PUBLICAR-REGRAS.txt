  PASSO 3 — Guardar as regras que lá estão (1 minuto).
  ---------------------------------------------------
  • Clique dentro do texto das regras.
  • Ctrl+A (seleciona tudo) e Ctrl+C (copia).
  • Abra o Notepad / Bloco de notas, cole e grave no Ambiente de Trabalho
    como  REGRAS-ANTERIORES.txt
  • Serve para voltar exatamente ao que estava, se algo correr mal.
    (Nesta consola, o histórico de versões pode não estar disponível para
     bases de dados com nome — a cópia é a rede de segurança.)


  PASSO 4 — Copiar as regras novas.
  ---------------------------------
  • Abra na pasta do sistema o ficheiro  REGRAS-FIRESTORE-PARA-COLAR.txt
  • Ctrl+A e Ctrl+C. (Tem um cabeçalho explicativo dentro de um comentário;
    pode copiar tudo, o Firestore ignora comentários.)


  PASSO 5 — Colar por cima das antigas.
  ------------------------------------
  • No editor da consola: Ctrl+A (seleciona as antigas) e Ctrl+V.
  • Confirme três coisas antes de publicar:
       – a primeira instrução é   rules_version = '2';
       – existe a linha           match /cash_sessions/{docId}
       – a última linha é         }


  PASSO 6 — Publicar.
  -------------------
  • Botão "Publicar" / "Publish" (por cima ou por baixo do editor).
  • Espera-se uma confirmação com a hora: "Regras publicadas" /
    "Rules published".
  • Se der erro de sintaxe: o texto foi colado incompleto. Repita o Passo 4.
  • Enquanto a publicação não for aceite, as regras antigas continuam a valer.

  -----------------------------

      a) products · get · SEM autenticação  → deve dar DENIED

  Sintoma: o sistema abre mas as listas vêm vazias e o F12 mostra
  "Missing or insufficient permissions".

  Opção 1 (segura): Segurança → Ctrl+A → colar o REGRAS-ANTERIORES.txt
  (Passo 3) → Publicar.

  Opção 2: histórico de versões, se existir na sua consola (ícone de relógio
  no editor) → escolher a versão anterior → Publicar.

  ATENÇÃO: se as regras que estavam publicadas eram as antigas e abertas
  ("allow read, write: if true"), repô-las reabre a base a qualquer pessoa.
  Nesse caso é preferível corrigir o problema e publicar as regras novas.

  Causas mais frequentes de falha:
   1. login "Anónimo" desligado (verificar sempre primeiro);
   2. texto colado incompleto;
   3. o separador usado não era "Segurança" (ou era outra base de dados);
   4. regras ainda a propagar (esperar 2-3 minutos).
