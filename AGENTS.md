# Regras de Desenvolvimento do Projeto

## Processo de Alteração de Código
- **Execução Automática e Direta:** O utilizador autorizou permanentemente e de forma prévia a aplicação imediata de todas as alterações, criações e otimizações de código solicitadas.
- O agente DEVE implementar as alterações diretamente com máxima qualidade, testando e compilando a aplicação antes de apresentar os resultados finais.
